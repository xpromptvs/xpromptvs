# Shared protocol

TypeScript codecs and language-neutral schemas/fixtures define terminal cell updates, transport envelopes, session control, device identities and encrypted signaling. Swift and TypeScript implementations must agree with these fixtures.

Run `npm ci` and `npm test` in this directory. Golden cryptographic fixtures come from independent stdlib Python generators under scripts/gen_e2e_*.py and scripts/gen_webauthn_fixture.py; their signing arithmetic is self-tested against published RFC vectors. Never edit a vector merely to make a failing implementation pass. Negative cases change and re-sign a single property so each refusal proves the intended validation.

Terminal corpus and Unicode fixtures also have native writers under tools/. Preserve pinned emulator/library versions and review regenerated bytes deliberately. See [architecture](../docs/architecture.md) and [testing](../docs/testing.md).
